# Application de facturation
Cette application calcule le total d'un achat et affiche le nom du client.
Compilation : javac -encoding UTF-8 Facture.java
Exécution : java Facture
Affichage : le nom du client, puis le total.
Frais de livraison : 5 dollars fixes s'ajoutent au total.
Scénario courant : 3 articles à 20 dollars plus 5 dollars de livraison donnent 65 dollars.
Détail : la deuxième ligne affiche la quantité et le prix unitaire des articles.
